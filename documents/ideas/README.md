# IDEAS — идеи развития

Идеи развития MTA Market, разложенные по темам.

**Наличие идеи в этом каталоге не означает обязательство её реализовать**
(правило унаследовано из старого `IDEAS/README.md`). Идея попадает в работу
только тогда, когда очередной Development Plan явно выбирает её как цель.

## Файлы

| Файл | Тема |
|---|---|
| [MARKETPLACE.md](MARKETPLACE.md) | Маркетплейс: модели/ассеты, продавцу, покупательский UX, монетизация и платежи. |
| [COMMUNITY.md](COMMUNITY.md) | Коммуникации: чаты, страница /status; форумные заметки. |
| [SERVERS.md](SERVERS.md) | Серверы: пока пуст по назначению, кандидаты — в CURRENT.md. |
| [TRUST.md](TRUST.md) | Доверие и конверсия, защита и форензика, менеджер лицензий. |
| [FUTURE.md](FUTURE.md) | Эксплуатация и зрелость (исторические кандидаты), антифичи. |

## Процесс отбора

Решение о том, какая тема станет следующей фазой, принимается
сопоставительным анализом foundational-документов — процесс описан в
[development/NEXT-PHASE.md](../development/NEXT-PHASE.md) (анализ ≠ план;
план создаётся отдельным решением по правилам
[development/README.md](../development/README.md)). Актуальное состояние
продукта — [development/CURRENT.md](../development/CURRENT.md) («Следующий
шаг»).
